## Mount and stop

Mounting is manual and requires explicit authorization:

1. Review the exact commit and candidate hashes.
2. Place the candidate files in an isolated plugin/profile location.
3. Supply a host wrapper that calls `createContextSubscriber(ctx)` and
   `createHostToolObserver({ subscribe, writer, origin })` explicitly.
4. Call `attach()` once; verify the returned health is `ok:true` and the trace
   header exists.
5. On stop, call `stop()` once. If it reports `asyncCleanupPending`, do not claim
   cleanup; wait for the health object to settle or keep the run marked
   unverified.
6. Preserve the trace as local evidence; do not rewrite it into a success
   report.

No step above is executed by this package.

## Failure handling

- `ctx.on` missing or returning a non-function: `SUBSCRIBE_FAILED`, no false
  success.
- Second subscription failure: prior disposers are called; if a callback may
  remain, `ownershipUncertain:true` and callbacks become inert.
- `writer.open`/accept/close failure: bounded `WRITE_FAILED`, primary stage kept
  separate from close failure.
- Async disposer: `stop()` returns `ok:false`, `asyncCleanupPending:true`; a
  rejection is caught and sets `asyncCleanupFailure`; it is never an unhandled
  rejection and never a claimed clean stop.
- No callback exception or sensitive value is propagated; diagnostics are fixed
  codes.

## Rollback

1. Stop the wrapper and confirm either `ok:true` or the explicit async/ownership
   status; never claim success from `asyncCleanupPending`.
2. Remove the wrapper/config entry; remove only the candidate files, not the
   profile's existing `tla-prelaunch-budget` link.
3. Keep the trace file as local evidence; do not delete the original.
4. Re-run the migration link audit and verify the existing budget plugin
   fingerprint is unchanged.
5. Do not refresh frozen handoff core hashes or the budget plugin's registered
   digest.

## B0/B1 name separation

- **B0** = launch receipts and runner/gate/budget join (`tla.runner-launch-receipt/v1`,
  `tla.gate-launch-receipt/v1`, `tla.run-evidence-bundle`). It binds a run; it
  does not observe tool calls.
- **B1** = tool metadata trace (`tla.tool-metadata-trace/v1`) and offline
  inspector. It observes tool-shaped callbacks; it does not prove a launch or a
  business closure.
- Neither package upgrades the synthetic acceptance protocol or V0.2 real-loop
  status.
