host run. `hostVerified=false`, `coverage=unknown`, `binding=unproven`, and the
real-host launch authorization is zero.

## Candidate payload

The M1A payload is the 11-file closure in
`docs/V0.2-OBSERVER-M1-PACKAGE-MANIFEST.json`
(`candidateSet=b1-observer-m1a`). The entry is
`orchestration/tool-observer/host-plugin/index.js`; its `package.json` declares
the private logical package `tla-tool-observer` (`type=module`,
`main=index.js`). The package has no npm dependencies: it uses Node built-ins and
relative repository modules only. It must remain separate from the budget
plugin.

The loader-shaped entry:

- exports named `name`, `inject`, `apply`;
- returns `undefined` when `{enabled:false}`;
- otherwise returns a `Promise<disposer>` and never the M0 controller;
- selects `host-notification` internally, not through a config field;
- rolls back bounded cleanup and throws a fixed code on setup failure;
- uses the returned disposer as the only cleanup effect.

The fake-loader tests are a contract model, not a real loader test. Do not import
or execute Cordis/DSH from the archive.

`--dump-config` mount claim. One captain/session only:

- no team creation, dispatch or repair;
- one known fixture read using the actual `file_path` schema;
- one harmless foreground `pwsh` marker using the actual `description` schema;
- no implementation writes, PTC/background jobs, web access or paid model;

Prerequisites: final source/fixture/payload pins, fresh project/runDir, verified
installed identities, full preflight, explicit installation/profile approval and
a separate one-run approval. This document produces no executable spec, launch
command or authorization token.

## What a future trial must report

- actual loader-compatible setup and attached journal for the selected
  identity;
- a trace containing the approved read and pwsh observation with session/call
  links and safe DTO; exact file-byte history is not implied;
- stopped journal plus independent controller/shutdown and process cleanup;
- complete B0 reconciliation and consistent local identity mapping;
- `hostVerified=false`; no business acceptance or synthetic closure is emitted.

Missing or contradictory facts produce partial/blocked. Process exit zero,
attached alone, forced shutdown, absent terminal journal or incomplete budget
reconciliation cannot be repaired after the fact. Member coverage, lossless
history, authentication, physical ordering and full repair remain unverified.
