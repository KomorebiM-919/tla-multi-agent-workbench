## Seam supported by evidence

`tools/result` is delivered after tool materialization and retains the exec
identity and final structured value on success. `scopeTarget` permits an
unscoped listener through the agent scope filter. The foreground-pwsh DTO can
carry `cwd`, `exitCode`, `signal`, timeout/abort and stdout/stderr truncation
facts.

This supports a same-process passive candidate. It does **not** prove live
member composition, fork seed replay, out-of-process child coverage, lossless
delivery, or a total physical order.

**What this proves:** the host uses a Cordis-style `ctx.on` subscription for

`session.id`, `exec.callId` and `exec.rootCallId` are real identifiers on that
path. It does **not** prove a public export, a stable `off`/dispose method, a
`tools/result` payload, a tool name, `isError`/value presence for normal results,
or member/session coverage. Those remain `unknown`; the default mapper still
reads only `exec.callId` and `exec.rootCallId`.


The default mapper reads only `exec.callId` and `exec.rootCallId`; it does not

support.

## Subscription API

The audited source shows a dispatcher-shaped seam but does not establish a
stable public Node API for this package. The adapter therefore accepts an
injected dispatcher with `on`/`off`, and an explicit `subscriptions` list. It
does not import DSH, auto-discover a dispatcher, install a plugin, or subscribe on
import.

The default subscription set is `['tools/result']`. `session/event` is available
only when the caller supplies a mapper and a dispatcher that exposes that event.
If the actual host API or field names differ, the correct result is an
unsupported adapter path or a recorded diagnostic, not a guessed API.

## Limits

- Source support is scoped to the audited entries; the archive is not a running
  Desktop process and no publisher signature is claimed.
- Delivery order is observer order, not physical execution order.
- Unknown identity remains null plus a diagnostic; no role, task, attempt or
  path is inferred from tool names.
- `hostVerified=false`, `coverage=unknown`, `binding=unproven` in every trace and
  report. This package does not install the observer or authorize a host run.
