## If installation is later authorized

Likely changes: one host-side plugin file (or bundled module), a profile-local
dependency entry and a config switch; the writer output path and record limits
must be explicit. The host bridge, writer and contract modules above are part of
the candidate, and the explicit-context adapter is implemented and offline-tested
against an invented context. The public Cordis/DSH context export, real member
coverage and live subscription lifecycle are still unsupported, so this package
is not installable as a working host observer yet. No dependency, profile or ACL
change is made here.

Rollback: remove the plugin/config entry, keep the trace file as local evidence,
and verify the old profile manifest/lock link still resolves. The existing
budget plugin fingerprint and the frozen handoff core hashes must not be
refreshed by this work. If a context adapter were later installed, its removal
must also dispose subscriptions and leave the profile's plugin links intact.

## Evidence still missing before a real run

1. A public, documented subscription and cancellation path; the injected
   `subscribe -> dispose` boundary is not evidence that DSH exposes it.
2. Live delivery of a normal `tools/result` payload and the stability of its
   audited fields; the source audit is static, not a runtime observation.
3. A session `tool/result` constructor/output shape for outcome/value; it stays
   unknown in this implementation.
4. Proof that delivery is lossless and how capture loss is reported.
5. A real launch receipt / runner-gate-budget join for the same run.
6. An explicit host launch authorization and a bounded test plan.
