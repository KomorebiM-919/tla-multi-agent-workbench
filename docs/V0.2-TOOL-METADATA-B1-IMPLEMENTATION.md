Importing the adapter has no side effects. `createToolObserver` requires an
explicit dispatcher with `on`/`off`, an explicit writer and an explicit
subscription list. The default subscription is only `tools/result`; the default
mapper projects only `exec.callId` and `exec.rootCallId`. Missing identity stays
null plus `FIELD_UNAVAILABLE`/inspection diagnostics.

## Trace and report semantics

- Trace schema: `tla.tool-metadata-trace/v1`; report schema:
  `tla.tool-metadata-report/v1`.
- Header origin is `simulated-dispatcher` by default; `host-notification` is a
  declared origin, never authenticated. Binding claims are assertions and remain
  `unproven`.
- `receiptSeq` is observer delivery order, not physical chronology.
- `VALID_METADATA` means file consistency only. It keeps `hostVerified=false`,
  `coverage=unknown`, `binding=unproven`, and is not a business verdict.
- The inspector never calls acceptance, synthetic collectors, the gate or a
  host. It writes a report to a fresh explicit path.

## Limits and failure handling

- Defaults: 8 MiB total, 10,000 observations, 1,000 pending, 16 KiB per record,
  128 diagnostics and 64 KiB footer reserve; 128 KiB minimum.
- Writer uses exclusive creation, loops on short writes, latches degradation and
  returns in-memory health even when no footer can be written.
- A successful footer is emitted before handle close; a close failure is returned
  separately and cannot be discovered from the file alone.
- Adapter callback exceptions are contained; subscriptions roll back on partial
  attach; `stop()` is idempotent and returns the retained health.
- Output path checks inspect existing ancestors with `lstat`, a mandatory
  `fsutil` reparse probe and `realpath`. If the probe is unavailable or its
  output is unexplained, the path is blocked; there is no realpath-only bypass.
  Concurrent TOCTOU is not guaranteed.

## Test coverage

`tests/v02-tool-trace.test.mjs` covers valid framing, out-of-delivery pairing,
exact/changed replay, missing identity, orphans, separate sessions, sequence and
schema errors, footer/trailing/BOM cases, short/partial writes, limits, close
faults, adapter rollback/exception containment, canaries and CLI exit codes
`0`/`2`/`1`.

No DSH module was imported or executed. The fixture origin is
`simulated-dispatcher`; these results do not prove live member coverage,
physical file bytes, receipt authentication, or a real repair-loop closure.
